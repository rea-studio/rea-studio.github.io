Universe 개인정보처리방침

시행일: 2026-10-13

1. 대상

Universe 는 소유자 한 사람이 본인의 Google 계정으로만 사용하는 개인용 도구입니다. 소유자 외의 사용자를 받지 않습니다.

2. 접근하는 Google 데이터

  • Gmail (읽기 전용, gmail.readonly) — 소유자 본인의 메일 제목·발신인·본문을 읽어 주제별 요약을 만듭니다. 메일을 보내거나 지우거나 고치지 않습니다.
  • YouTube (업로드, youtube.upload) — 소유자 본인의 채널에 본인이 만든 영상을 올립니다.

3. 저장과 보관

인증 토큰과 요약 결과는 소유자가 직접 관리하는 개인 컴퓨터에만 저장됩니다. 외부 서버로 옮기지 않습니다. 소유자가 원하면 언제든 지울 수 있습니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 판매·양도·공유하지 않으며, 광고에 쓰지 않습니다. 요약을 만들 때 메일 내용의 일부가 소유자가 계약한 AI 모델 제공자에게 처리 목적으로만 전달될 수 있습니다.

5. Google API 정책

Universe 가 Google API 로 받은 정보의 사용과 이전은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 접근 철회

Google 계정 권한 페이지에서 언제든 Universe 의 접근을 해제할 수 있습니다.

7. 문의

이 저장소의 Issues로 연락할 수 있습니다.

English summary

Universe is a single-user personal tool. It accesses only the owner's own Gmail (read-only) and YouTube (upload). Tokens and results are stored on the owner's own computer, are not sold or shared with third parties, and are not used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account permissions page.
